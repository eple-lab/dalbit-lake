## 1. 무엇을

달빛이 비치는 여름밤 호수 숲을 팅커벨이 되어 날아다니며, 반딧불이 5마리를 투명한 유리병에 담는 힐링 **3D 게임**.

- **메인 화면 = 팅커벨의 눈으로 보는 1인칭 3D**: 플레이어가 곧 팅커벨이고, 화면 가장자리에 팔·다리가 은근슬쩍 보입니다.
- **오른쪽 위 작은 창 = 3인칭 3D**: 팅커벨의 왼쪽 위에서 비스듬히 내려다보며 따라갑니다. 호수·나무·반딧불이·하늘·달이 모두 입체로 보이고, 팅커벨은 창 크기의 약 1/5, 창에는 전체 맵의 약 1/5만 보입니다.

핵심 재미는 **"느긋하게 다가가기"** 입니다. 서두르면 반딧불이가 흩어지고, 천천히 다가가 손을 내밀면 반딧불이가 스스로 날아와 손등에 앉습니다.

## 2. 누가

| 항목 | 내용 |
| --- | --- |
| 플레이어 | 잠깐 쉬어 가며 힐링하고 싶은 사람, 과제를 확인하는 동료 |
| 기기 | PC 키보드 (주), 휴대폰 (화면 버튼으로 조작) |

| 피할 것 | 무섭거나 놀라게 하는 연출, 어지러운 화면 움직임 |

## 3. 조작

| 키 | 동작 |
| --- | --- |
| W | 위로 날아오르기 |
| S | 아래로 내려가기 |
| A / ← | 왼쪽으로 방향 돌리기 |
| D / → | 오른쪽으로 방향 돌리기 |
| ↑ | 누르고 있는 동안 빨라짐 (떼면 점점 느려짐) |
| ↓ | 누르고 있는 동안 금방 느려짐 — 멈추면 둥둥 |
| [ | 왼손 올리기 |
| ] | 오른손 올리기 |
| \ (엔터 위) | 손등의 반딧불이를 두 손으로 감싸 병에 담기 |
| Ctrl + C | 일시정지 + "계속할까요? / 그만할까요?" 창 |
| 오른쪽 위 버튼 | "그만하기" — Ctrl + C와 같은 창 |

- 앞으로 가는 힘은 속도가 정합니다. W S A D는 높이와 방향만 바꿉니다.
- A / D는 "옆으로 미끄러지기"가 아니라 "고개와 몸을 돌리기"입니다.
- 화면 아래에 키 모양 안내를 항상 보여 주고, 누르고 있는 키는 불이 켜집니다.
- 휴대폰에서는 이 키 안내를 손가락으로 눌러 같은 동작을 합니다.
- 브라우저에서 Ctrl + C는 원래 "복사"이지만, 게임 화면에서는 복사 대신 멈춤 창을 띄웁니다.
- 한글 입력 상태여도 키가 동작하게 합니다 (글자가 아니라 키 위치로 인식).

## 4. 규칙

### 4-1. 비행과 속도

- **↑ 를 누르고 있는 동안 빨라지고**(약 1.5초면 최고 속도), **손을 떼면 점점 느려지고**(최고 속도에서 약 10초), **↓ 를 누르면 금방 멈춥니다**(약 1초).
- 화면 표시는 0 ~ 4단계로 나눠 보여 줍니다.
  - 0단계: 둥둥 떠 있음. 멈춰 있을수록 위아래로 더 크게 둥둥, 살짝 좌우로 흔들림
  - 1~2단계: 느림 — 반딧불이가 놀라지 않음
  - 3~4단계: 빠름 — 반딧불이 근처를 지나가면 흩어짐
- 현재 속도는 색과 문구로 표시: 둥둥(하늘색) / 느림(초록) / 빠름(주황).
- 맵 크기: 호수 반지름 28, 날 수 있는 범위 반지름 72 (첫 버전의 약 60%).
- 맵 가장자리(숲 바깥)에 가면 부드럽게 방향이 돌아갑니다. 땅이나 물에 닿기 직전, 나무 꼭대기보다 조금 높은 곳에서 더 못 가게 막습니다.

### 4-2. 반딧불이

- 무리 지어 있는 반딧불이와 혼자 나는 반딧불이가 섞여 있습니다.
- 빠른 속도(3~4단계)로 가까이 오면 → **흩어짐**: 사방으로 날아갔다가 잠시 뒤 다시 모입니다.
- 느린 속도로 가까이(약 13 거리 안) 와서 손([ 또는 ])을 올리면 → **다가옴**: 가장 가까운 반딧불이가 천천히 날아와 손등에 **앉음**.
- 다가오거나 손등에 있는 반딧불이는 더 크고 밝게 빛납니다.
- 손을 내밀면 다가올 반딧불이가 근처에 있으면 "손을 올려보세요 [ 왼손 / ] 오른손" 안내가 나옵니다.
- 손등에 앉은 상태에서 \ → **담기 동작**: 몸을 웅크리며 두 손을 오므려 반딧불이를 감싸고, 투명한 병을 앞으로 가져와 살포시 넣고 뚜껑을 닫습니다 (약 2초, 1인칭 화면에서 손과 병이 보임). 병 속 빛이 하나 늘어납니다.
- 담기 동작 중에는 이동하지 않고 둥둥 떠 있습니다.
- 손은 키를 누르고 있는 동안만 올라가 있습니다. 손을 내리면 앉아 있던 반딧불이는 날아갑니다.
- 손등에는 한 번에 한 마리만 앉습니다. 왼손·오른손은 어느 쪽 반딧불이를 부르느냐만 다릅니다.

### 4-3. 호수의 수호신 용

- 길고 가는 몸이 **지렁이처럼** 위아래·옆으로 꿈틀거리며 헤엄칩니다. 큰 눈이 몇 초마다 깜박입니다.
- 반딧불이는 용을 좋아해서 **용 근처에 반딧불이가 많이 모입니다**.
- 요정이 다가가면 용이 눈을 가늘게 뜨고 반깁니다. 그 밖에 게임 규칙에 끼어들지는 않습니다.
- 용과 부딪혀도 벌칙은 없고, 부드럽게 밀려납니다.

### 4-4. 나무

- 나무 종류: 판타지처럼 아주 길고 큰 나무 / 넓고 짧은 나무 / 길고 가는 나무. 빽빽하지 않게 호수를 둘러쌉니다.
- 호수 위에도 작은 섬 세 개에 낮은 가지가 있는 작은 나무가 있어, 호수 한가운데서도 앉아 쉴 수 있습니다.
- 나무에 부딪히면 **"따콩!"** 소리와 함께 화면에 글자가 나오고, 팅커벨이 살짝 튕겨 나갑니다.
- 따콩 벌칙: **손등에 앉아 있던 반딧불이만 놀라 날아가고, 1초 동안 비틀거립니다.** 병에 담긴 반딧불이는 그대로입니다.
- 나무에 앉아 쉬기: 속도 0(둥둥)일 때 가지 위에 닿으면 **자동으로 앉습니다**. 이동 키나 ↑ 를 누르면 다시 날아오릅니다.
  - 앉아 있는 동안 1인칭 화면 아래에 가지 위에 걸친 **두 다리**가 보이고, 가끔 손이 올라와 **날개를 다듬는** 동작을 합니다.
  - 작은 창에서는 가지 위에 앉은 팅커벨이 보입니다.

### 4-5. 끝나는 조건

- **성공**: 반딧불이 5마리를 병에 담으면 → 병이 환하게 빛나며 "반딧불이 다섯 친구가 병 속에서 반짝여요. 오늘 밤은 참 따뜻하네요 ✨" → 결과(걸린 시간)와 다시하기·메인으로 버튼. 보통 2분 안팎에 성공하는 난이도.
- **시간**: 제한시간 3분. 3분이 되면 → "계속할까요? / 그만할까요?" 창. 계속하면 **담은 반딧불이는 그대로, 시간만 3분 더** 줍니다.
- **그만하기**: 오른쪽 위 버튼이나 Ctrl + C → 같은 창. "그만할까요"를 고르면 처음 화면으로, "계속할까요"를 고르면 이어서 진행.

## 5. 화면

| 요소 | 설명 |
| --- | --- |
| 배경 | 달빛이 비치는 커다란 호수, 둘레의 나무들, 여름밤 하늘 (3D 공간) |
| 메인 화면 (1인칭) | 팅커벨의 눈높이. 날 때는 화면 아래·옆으로 팔과 다리 끝이 은근슬쩍 보이고, 손을 올리면([ ]) 해당 손이 화면 안으로 들어옴 |
| 오른쪽 위 | 맨 오른쪽 위에 **그만하기 버튼**, 그 바로 아래에 **작은 창** |
| 작은 창 (3인칭) | 팅커벨의 왼쪽 뒤 위에서 비스듬히 내려다보며 따라가는 카메라. 팅커벨은 창의 약 1/5 크기 (날개 반짝임, 요정 가루), 창에는 전체 맵의 약 1/5 범위만 보임. 호수·나무·반딧불이·하늘·달 모두 입체로 보임 |
| 담기 동작 | 몸을 웅크리고 두 손을 모아 반딧불이를 감싼 뒤 투명한 병에 넣는 장면 |
| 나무 위 휴식 | 가지에 걸친 두 다리, 날개를 다듬는 손 |
| 반딧불이 | 깜빡이는 연두·노란 빛 |
| 유리병 | 투명하고 귀여운 병. 담긴 수(0~5)만큼 병 안이 밝아짐 |
| 호수의 수호신 용 | 온화하고 예쁘고 따뜻한 느낌. 길고 가는 몸이 지렁이처럼 꿈틀거리며 헤엄치고, 큰 눈을 깜박임. 반딧불이가 곁을 맴돎 |
| 생물 | 밤하늘을 나는 새, 숲가를 돌아다니는 사슴과 토끼 (게임에 방해되지 않는 배경 생물) |
| 상단 정보 | 남은 시간, 병(0/5), 현재 속도 상태 |
| 하단 키 안내 | W A S D, ↑ ↓, [ ], \ 모양. 누르는 키에 불이 켜짐. 휴대폰에서는 누르는 버튼 |
| 숨 쉬는 화면 | 화면 전체가 들숨·날숨처럼 아주 천천히 위아래로 몇 픽셀만 움직임 (약 4초 주기) |

### 상태 표시 (색 + 문구를 함께)

| 상태 | 화면 표현 |
| --- | --- |
| 둥둥 / 느림 / 빠름 | 상단 속도 표시 색과 문구 |
| 흩어짐 | 반딧불이가 사방으로 퍼지고 "앗, 너무 빨랐어요" 문구 |
| 다가옴 | 반딧불이 빛이 부드럽게 커지며 손 쪽으로 이동 |
| 손등에 앉음 | 손 주변이 따뜻하게 빛남, "\ 키로 살포시 담아요" 안내 |
| 병에 담김 | 병 쪽으로 빛이 날아가 들어감, 병의 빛 +1 |
| 따콩! | 큰 글자 "따콩!", 별 모양 효과, 효과음, 1초 비틀거림 |
| 나무 위 휴식 | 팅커벨이 가지 위에 앉음, "쉬는 중" 문구 |
| 용 곁 | 용이 눈을 가늘게 뜨고 반김 |
| 일시정지 | 화면이 어두워지고 계속/그만 창 |

## 6. 소리

- 따콩: 짧고 귀여운 효과음 (파일 없이 브라우저에서 직접 만든 소리).
- 반딧불이를 담을 때 맑은 "띵" 소리, 성공할 때 짧은 멜로디.
- 배경음(풀벌레, 물소리)은 이번 판에서 빼고, 소리 켜기/끄기 버튼을 그만하기 버튼 옆에 둡니다.

## 7. 예외 상황

| 상황 | 처리 |
| --- | --- |
| 맵 바깥으로 날아가려 함 | 가장자리에서 부드럽게 방향이 돌아감 |
| 손등에 반딧불이가 없는데 \ 를 누름 | 아무 일도 없음 ("손을 먼저 내밀어요" 안내) |
| 양손을 동시에 올림 | 먼저 올린 손만 인정 |
| 성공 직후 3분이 됨 | 성공이 먼저 |
| 일시정지 중 | 시간이 멈추고 키 입력은 창에서만 동작 |
| 창을 다른 탭으로 옮김 | 자동으로 일시정지 |
| 휴대폰 (키보드 없음) | 화면 아래 키 버튼을 손가락으로 누르면 같은 동작 |

## 8. 만들기 범위

- 파일: `fireflies/index.html`, `fireflies/styles.css`, `fireflies/script.js` (세 겹 분리).
- 3D는 **Three.js**(웹에서 3D를 그리는 공개 라이브러리)를 CDN으로 불러와 그립니다. 이미지·모델 파일 없이 코드로 만듭니다.
- 나무·용·사슴·토끼·새는 단순한 도형을 조합한 **로우폴리(각진 동화풍)** 모양입니다. 사실적인 모델은 이번 범위가 아닙니다.
- 작은 창은 같은 3D 장면을 팅커벨 왼쪽 위에서 따라가는 두 번째 카메라로 한 번 더 그립니다.
- 메인 페이지의 "준비 중" 카드를 `fireflies/` 플레이 링크로 바꿉니다.
- 다음 루프로 미루는 것: 배경음, 레벨, 기록 저장.

| 확인 항목 | 결과 | 다음 수정 지시 |
| --- | --- | --- |
| 메인에서 카드를 누르면 게임이 열리고, 게임에서 메인으로 돌아올 수 있는가 | | |
| 1인칭 화면에 팔·다리가 은근히 보이는가 | | |
| 오른쪽 위 작은 창에 3인칭으로 팅커벨(창의 1/5)과 주변(맵의 1/5)이 보이는가 | | |
| 그만하기 버튼과 작은 창이 겹치지 않는가 | | |
| W S 높이, A D·← → 방향, ↑ 누르면 빨라지고 떼면 점점 느려지는가, 멈추면 크게 둥둥 떠 있는가 | | |

| \ 를 누르면 웅크려 손을 모아 병에 넣는 동작이 보이고, 병의 빛과 숫자가 늘어나는가 | | |
| 나무에 부딪히면 따콩 소리·글자·튕김, 손등 반딧불이만 날아가는가 | | |
| 둥둥 상태로 가지에 닿으면 앉고, 다리와 날개 다듬는 손이 보이는가 | | |
