# 별빛 받기

달빛 호수 위의 작은 배를 움직여 하늘에서 떨어지는 별빛을 담는 2D 게임입니다.

👉 플레이: https://eple-lab.github.io/dalbit-lake/starlight/

## 규칙

| 떨어지는 것 | 받으면 |
| --- | --- |
| ⭐ 하얀 별 | +1점 |
| 🌟 황금 별 (반딧불이처럼 커졌다 작아지며 반짝임) | +5점 |
| 🟣 그림자 방울 | 달 하나를 잃음 (달 3개를 모두 잃으면 끝) |

- 연속으로 5개를 담을 때마다 점수 배율이 1씩 올라갑니다. 별을 놓치면 연속 기록이 0이 됩니다.
- 연속 기록이 길수록 달과 물에 비친 달빛이 밝아집니다.
- 시간이 갈수록 별이 빨리, 자주 떨어지고 그림자 방울도 늘어납니다.
- 최고 기록은 브라우저에 저장됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| ← → 또는 A D | 배 이동 |
| 마우스 / 터치 | 누른 곳으로 배 이동 |
| Space / Enter | 시작 |
| Esc 또는 오른쪽 위 "그만하기" | 처음 화면으로 |

## 연출

- 별을 받으면 빛 고리, 빛기둥, 반짝이가 "화악" 퍼집니다.
- 달을 모두 잃으면 화면 가득 별이 쏟아진 뒤 결과가 나옵니다.
